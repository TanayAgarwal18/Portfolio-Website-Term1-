# My Portfolio

## About

Personal portfolio of **Tanay Agarwal**, a first-year BSc CS & AI student who loves problem solving and learns best by building projects. The site uses a dark developer-terminal look with a CSS Grid bento layout and neon cyan accents, and includes a CSS-only light/dark theme switch.

## Technologies

- HTML
- CSS (Flexbox, Grid, positioning, transitions, keyframe animations, media queries, custom cursor)

No JavaScript, no frameworks.

## Projects

### Student Portal

A college student portal built with semantic HTML: profile and schedule tables, a skills list and a course registration form.
Live: `projects/student-portal.html`

### Flexbox Quest

A mini game interface built entirely with Flexbox and made responsive with media queries.
Live: `projects/flexbox-quest/index.html`

### This Portfolio

Terminal-style hero, bento layout, sticky nav, CSS-only theme toggle and scroll animations.

### Textile Management System

A Python + MySQL console application (CBSE Class XII Computer Science project, group project) that manages a textile business: buyers, suppliers, inventory, orders, supplier orders, employees, shipping and payments, with insert, update, delete, view and search on every table. It is a desktop console program, so there is no live demo.

## CSS Features Used

| Feature | Where |
|---|---|
| Flexbox | Navbar, buttons, tags, timeline, form, footer |
| CSS Grid | Hero, About bento, Skills, Projects, Contact |
| `position: sticky` | Navbar |
| `position: fixed` | Animated background blobs |
| `position: absolute` / `relative` | Floating symbols, timeline line and dots, mobile menu |
| `z-index` | Navbar above content, background behind content |
| Transitions | Buttons, cards, nav links, theme change |
| Keyframe animations | Typing text, floating shapes, background drift, spinning avatar ring, scroll reveal |
| Custom cursor | `cursor: url(...)` with an inline SVG, site-wide |
| Media queries | Tablet (900px) and phone (700px) layouts, reduced motion |
| CSS variables | Colour theme and light/dark switch |
