project case study

Textile Management System

A Python and MySQL console application that replaces paper records in a textile business with one central database.

  • Python
  • MySQL
  • SQL
  • mysql.connector

CBSE Class XII Computer Science project, 2025–2026. It runs in the terminal, so this page is the walkthrough instead of a live demo.

01 — why it exists

The problem

Paper records don't scale

Managing a textile business by hand leads to errors in record-keeping, duplicated data and no easy way to track stock. Paper files are slow to update, easy to lose and hard to search.

This system keeps buyers, suppliers, stock, orders, staff, shipping and payments in one database, so the data is quick to find, easy to update and stored safely.

02 — what it does

The 8 modules

Buyer Details

Customer records with contact information, GST number and shipping details.

Buyer ID, name, shipping address, email, GST number, contact

Supplier Details

Supplier contact data, payment terms and an overall service rating.

Supplier ID, name, contact person, address, payment terms, rating

Inventory

Fabric, yarn and finished products with their material, size and pattern.

Product ID, name, description, category, size, material, fabric type, pattern

Orders

Orders placed by buyers: items, quantity, pricing, status and tracking number.

Order ID, buyer, date, status, product, quantity, total price, shipping address, tracking number

Supplier Orders

Orders placed with suppliers for raw material or finished goods, including a fine for late delivery.

Supplier ID, order ID, material, fabric type, quantity, total cost, fine, shipping address

Employee Details

Staff records, departments and payroll-related data.

Employee ID, name, department, salary, hire and termination date, attendance, overtime

Shipping Details

Shipping records that keep order tracking and delivery on time.

Order ID, buyer ID, status, items shipped, shipping address, shipping method

Payment Details

Payments, due dates, remaining balance and penalties.

Order ID, due date, total amount, remaining payment, method, status, fine

03 — how each module works

Five operations on every table

Insert

INSERT INTO ...

Asks for each field, adds the record and confirms.

Update

UPDATE ... WHERE id

Finds a record by its ID and changes the chosen values.

Delete

DELETE ... WHERE id

Removes a record and shows how many were deleted.

View

SELECT * FROM ...

Fetches every record and prints each one.

Search

SELECT ... WHERE id

Looks up one record by ID, or says if there is no match.

04 — under the hood

How Python talks to MySQL

  1. Import the mysql.connector module to communicate with the database.
  2. Connect with connect() using the host, user, password and database name.
  3. Create a cursor with cursor() to run SQL operations.
  4. Run the query with execute().
  5. Read the results with fetchall(), fetchone() or fetchmany().
  6. Close the connection with close() when the work is done.
